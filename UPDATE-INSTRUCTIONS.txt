Duel Club - show the whole photo without cropping

This patch changes only public/styles.css.
It leaves the wide, side-by-side voting layout, functionality, media uploads,
256 contenders, collaborative studios, and delete permissions unchanged.

Install in GitHub:
1. Open https://github.com/lowerx/Duel-Club
2. Open the public folder.
3. Replace public/styles.css with the styles.css in this ZIP.
4. Commit to main; allow Render to redeploy.
5. Refresh your website with Cmd+Shift+R.

What changes:
- Voting: each photo, GIF or video is entirely visible inside its half-width box.
- Pack detail contender thumbnails and shared/solo creator preview tiles: no cropping.
- Champion media and pack covers: no cropping.
- Unused space may be shown as dark bars at the sides or top/bottom.

If a source photo was cropped BEFORE being uploaded (e.g. the original image
file already lacks part of a head), CSS cannot restore missing image pixels.
